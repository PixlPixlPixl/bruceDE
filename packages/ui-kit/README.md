# @brucede/ui-kit

Optional shared theme tokens and reusable UI primitives for BruceDE plugins. This package is convenience, not a required component framework: plugins may build their own React/TSX, CSS, SVG, canvas, or native Theia widgets.

Import `@brucede/ui-kit/theme.css` to use the shared spacing and radius tokens. Prefer Theia theme variables for foregrounds, backgrounds, and semantic colors so plugins follow the active host theme.
